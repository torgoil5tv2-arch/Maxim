# 🚀 Інструкція з деплою сайту MONO.DROP на Render.com (24/7 безкоштовно)

Ця інструкція дозволить запустити ваш інтернет-магазин у хмарі **Render.com** з автоматичним оновленням при кожному пуші на GitHub. Сайт працюватиме **цілодобово 24/7**, з будь-якого мобільного інтернету (Kyivstar, Vodafone, lifecell) та без увімкненого домашнього комп'ютера.

---

## Крок 1. Завантаження оновленого коду на GitHub

Відкрийте термінал (PowerShell або Git Bash) у папці проєкту (`d:\сайт`) та виконайте команди:

```bash
git add .
git commit -m "Ready for Render.com deployment"
git push origin main
```

*(Якщо ви працюєте з гілкою `master` замість `main`, використовуйте `git push origin master`).*

> **Примітка:** Ми додали `.gitignore`, тому важкий локальний бінарник `cloudflared.exe` (55 МБ) та тимчасові файли не потраплять у репозиторій.

---

## Крок 2. Підключення репозиторію на Render.com

1. Перейдіть на сайт **[render.com](https://render.com)** та увійдіть через ваш **GitHub-акаунт**.
2. На головній панелі (Dashboard) натисніть синю кнопку **New +** (вгорі праворуч) та оберіть **Web Service**.
3. У списку репозиторіїв знайдіть ваш репозиторій магазину та натисніть **Connect**.

---

## Крок 3. Налаштування параметрів веб-сервісу

Заповніть форму наступними значеннями:

| Параметр | Значення | Пояснення |
|:---|:---|:---|
| **Name** | `mono-drop` *(або ваша назва)* | Буде частиною посилання: `mono-drop.onrender.com` |
| **Region** | **Frankfurt (EU)** | Найближчий дата-центр до України з мінімальним пінгом |
| **Branch** | `main` *(або `master`)* | Головна гілка з вашим кодом |
| **Root Directory** | *(залиште пустим)* | Корінь проєкту |
| **Runtime** | **Python 3** | Середовище виконання |
| **Build Command** | `pip install -r requirements.txt` | Встановлення Flask, Gunicorn та залежностей |
| **Start Command** | `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 120` | Продакшн WSGI-сервер із підтримкою мультипоточності |
| **Instance Type** | **Free ($0/month)** | Повністю безплатний тариф |

---

## Крок 4. Змінні оточення (Environment Variables) — Опціонально

Прокрутіть сторінку вниз до розділу **Environment Variables** (натисніть *Add Environment Variable*), якщо хочете змінити стандартні налаштування:

* `ADMIN_PIN` — секретний PIN для додавання товарів (за замовчуванням `7777`).
* `TELEGRAM_BOT_TOKEN` — токен бота для сповіщень про замовлення.
* `TELEGRAM_CHAT_ID` — ваш chat ID у Telegram.
* `PYTHON_VERSION` — `3.11.9` (рекомендовано для швидкої збірки).

---

## Крок 5. Запуск та отримання постійного посилання

1. Натисніть кнопку **Deploy Web Service** унизу сторінки.
2. Почнеться процес збірки (займає 1–2 хвилини). У вкладці **Logs** ви побачите повідомлення:
   ```text
   ==> Build successful 🎉
   ==> Deploying...
   [INFO] Starting gunicorn 21.2.0
   [INFO] Listening at: http://0.0.0.0:10000
   ==> Your service is live 🚀
   ```
3. Вгорі зліва під назвою сервісу з'явиться постійне посилання вашого сайту:
   👉 **`https://mono-drop.onrender.com`** *(або обране вами ім'я)*.

---

## ✨ Переваги такого рішення:
* 🌐 **Постійна адреса:** Посилання більше ніколи не змінюється після перезавантаження.
* 📱 **TikTok та соцмережі:** Посилання відкривається у вбудованих браузерах TikTok, Instagram та Telegram без будь-яких попереджень або блокувань.
* ⚡ **Автоматичний редеплой:** Кожного разу, коли ви робите `git push origin main`, Render автоматично підтягує свіжі зміни та оновлює сайт за 60 секунд.
